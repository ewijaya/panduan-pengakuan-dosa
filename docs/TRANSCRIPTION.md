# Sakramen Tobat (Pengakuan Dosa) — Digitized Booklet

Verbatim Indonesian transcription of a 17-photo scan of the booklet **"Sakramen Tobat (Pengakuan Dosa)"**, published openly by **Keuskupan Surabaya** (Nihil Obstat 15 Juli 2019, Imprimatur 16 Juli 2019).

## Structure

- `content/images/` — original photos, renamed `img-01.jpeg` … `img-17.jpeg` in booklet order (original WhatsApp timestamp order, verified against printed page numbers).
- `content/pages/` — one markdown file per photo, transcribed 100% verbatim (printed typos preserved, e.g. "pemyembahan", "saya saya berdusta", "dioakan").
- `content/booklet-full.md` — all pages concatenated in order, for single-file use.

## Transcription conventions

- Text is verbatim Indonesian as printed — no translation, no typo correction.
- Each file header records the source image and printed page number; the printed page number is repeated in italics at the end of the file (where visible).
- Words hyphenated across line breaks in print were rejoined (e.g. "Sakra-men" → "Sakramen").
- Two-column liturgical dialogue (Umat / Imam) on img-15…17 is rendered as markdown tables.
- Illegible text would be marked `[tidak terbaca]` (none was needed).
